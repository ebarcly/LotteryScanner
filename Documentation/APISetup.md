# API Setup Instructions

This app uses RapidAPI for lottery number verification. To use the app:

1. Sign up for a RapidAPI account at https://rapidapi.com

2. Subscribe to the lottery API services:
POWERBALL: https://rapidapi.com/avoratechnology/api/powerball
MEGAMILLIONS: https://rapidapi.com/avoratechnology/api/mega-millions

3. Get your API key

4. Create `Config.xcconfig` in Resources/Configuration: RAPID_API_KEY = your_api_key_here

Note: Never commit your API keys to GitHub!
